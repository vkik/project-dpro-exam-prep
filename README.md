# Project DPro Exam Prep

Study tools for the **Project DPro (PMD Pro) Foundation exam**, based on the *Project DPro Guide, 2nd Edition*.

| Page | What it does |
| --- | --- |
| [`index.html`](index.html) | Interactive reader: the Guide retold in nine short chapters, with exam-style questions after each chapter, a 61-card recall deck for every list the exam asks, reading progress and text size controls |
| [`mock-exam.html`](mock-exam.html) | 75-question mock exam weighted like the syllabus, with exam and practice modes, score by area, and an explanation plus Guide reference for every answer |

## Exam facts

- 75 multiple-choice questions
- Pass mark: 49 correct (65%)
- No negative marking: answer every question
- Personal target: 60 correct (80%); book the exam after two mock scores of 64 or more

## Using it

Both pages are single self-contained HTML files. Open them in any browser, or enable GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/`) to get a link that works on a phone.

Progress, quiz results and recent scores are saved in the browser's local storage only; nothing is sent anywhere.
